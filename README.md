# ClassCard Auto Study (클래스카드 자동 학습기)

클래스카드(ClassCard)의 초록색 **단어 세트**를 자동으로 학습(암기 ➔ 리콜 ➔ 스펠)해 주는 Selenium 기반 자동화 프로그램입니다.

---

## 🌟 주요 기능
1. **암기 / 리콜 / 스펠 학습 완전 자동화**
   - 단어 세트 진입 후 시작 버튼, 카드 뒤집기, 정답 클릭/입력, 구간 완료 팝업 등을 자동으로 수행합니다.
2. **학생 리포트 분석 기반 자동 건너뛰기**
   - 이미 **100% 이상** 완료된 학습은 불필요하게 다시 하지 않고 자동으로 스킵합니다.
3. **백그라운드 이벤트 처리**
   - 브라우저 내부 JavaScript 이벤트를 기반으로 동작하므로, 창 포커스가 벗어나거나 다른 창 뒤에 있어도 안정적으로 실행됩니다.
4. **차후 업데이트 예정**
   - 📢 **테스트(Test) 기능은 차후 업데이트를 통해 지원될 예정입니다.**

---

## 🚀 사전 준비 (요구사항)
- **Python 3.10+** 설치
- **Google Chrome** 브라우저 설치
- 필요 라이브러리 설치:
  ```bash
  pip install selenium
  ```

---

## 💻 사용 방법

### 1. 실행하기
- Windows: `실행.bat` 더블 클릭  
  *또는 콘솔에서 아래 명령 실행:*
  ```bash
  python classcard_auto.py
  ```

### 2. 콘솔 안내 확인
- 프로그램 실행 시 출력되는 **사용법 및 주의사항**을 확인한 뒤 `Enter` 키를 누릅니다.

### 3. 계정 및 클래스 URL 입력
1. **아이디**: ClassCard 로그인 아이디(이메일 또는 ID) 입력
2. **비밀번호**: ClassCard 비밀번호 입력
3. **클래스 URL**: 학습할 클래스의 메인 URL 입력 (예: `https://www.classcard.net/ClassMain/클래스ID`)

### 4. 세트 목록 확인 후 학습 시작
- 프로그램이 클래스 내 세트 진도율을 조회하여 목록을 표시합니다.
- `y`를 입력하면 자동으로 학습이 진행됩니다.

---

## ⚠️ 주의사항
- 크롬 브라우저 창을 **최소화**하거나 **강제 종료**하지 마세요. (화면 뒤에 두거나 다른 창으로 가리는 것은 괜찮습니다)
- 본 프로그램은 개인 학습 보조 및 연구 목적으로 제작되었습니다.
